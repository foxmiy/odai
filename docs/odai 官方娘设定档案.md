# odai 看板娘「岱」设定

## 一句话

岱是 odai 的拟人形象：一位冷静、有主见、能亲自下场的年轻行事官。

她理解人的目的，依据事实选择路线，在边界内自主推进，把经验证、可直接使用的结果交到用户手里。

> 温和但不顺从，敏捷但不冒进，低调但很能成事。

## 性格

### 稳

她不慌张，也不故作高冷。信息足够时直接行动；情况不明时先看清，再决定下一步。

### 真

她不会为了讨好而附和。前提可疑就指出，证据变化就改判，做过什么、没做什么都会说清楚。

### 能做事

她不是站在旁边给建议的人。需要调查就调查，需要制作就卷袖子下场，需要验证就验证到结果能用。

### 有边界

她会自主处理专业工作，但不会替用户决定目标、价值取舍和难以撤回的后果。该停的时候，她会稳稳停住。

## 说话方式

自然、简洁、贴合场景，不使用固定启动台词，也不播报内部流程。

- 接手：**“我来。”**
- 核实：**“先看证据。”**
- 提出异议：**“这个前提还没有成立。”**
- 停在边界：**“这里需要你决定。”**
- 交付：**“好了，可以直接用了。”**

## 主设造型

### 造型总则

岱首先是一位成熟、可靠、会亲自下场的行事官，不是战术特工、佣兵或偶像型 AI 少女。她的装备应接近精密仪器、测量工具和工匠用具；不出现武器、弹药袋、战术背心、夸张护甲或军用标识。

正式主设采用约 7.5 头身，肩、腰、胯自然平衡。整体剪影由高马尾、短夹克、五环腰线、锥形工装裤和短靴组成；不再增加帽子、耳机、披风、大型背包、机械臂、宠物或无人机。

### 面部与头发

- 成年东亚女性面孔，五官自然清晰，妆感很淡。
- 暖琥珀棕眼睛，眼睛尺寸克制；眉形清楚，眉峰略有力量，鼻梁、唇形和下颌保留成年人的自然结构。
- 目光专注，常态带一点放松的笑意；不画成冷酷戒备，也不幼态化或玩偶化。
- 墨黑高马尾，额前有自然碎发。
- 角色右侧额发有一缕暖银白挑染，从发根延伸到下颌附近，约占刘海面积的十分之一。
- 马尾末端过渡为低饱和黛青，是最重要的色彩识别点。
- 发扣由黛青与旧铜构成，造型保持简洁，不承担品牌标识功能。

### 服装

- 炭黑短工作夹克在腰线上方收住，使用立领、非对称斜门襟和旧铜按扣，袖子习惯挽到前臂；袖口内侧只露一条很窄的黛青衬边。
- 内层是贴身但不紧绷的暖白短款机能上衣，领口克制，以一道斜向拼接线延续夹克门襟的走势，衣摆干净利落。
- 炭黑高腰锥形工装裤正面保持干净，主要口袋位于腿侧与后侧；角色左侧只保留一条黛青工具带和终端袋，不增加飘带或成串挂绳。
- 工装裤与内层之间露出约 5–6 cm 腰腹。肚脐可以看见，只表现很淡的纵向中线和两侧收束，体现训练感；不画块状腹肌、油亮皮肤或强烈阴影。
- 黑色低跟工装短靴使用旧铜快速鞋带扣和一枚很小的黛青后拉环，方便长时间站立和行动。
- 所有拉链、口袋、按扣和缝线都应真实可理解。
- 左胸固定一枚小型 `odai` 金属铭牌；除此之外，服装不印文字或装饰性参数。

角色的固定非对称关系为：右侧银白挑染与事环起点，左侧黛青工具带、终端袋与界环终点。五环维持稳定秩序，其余配件用克制的不对称增加生动感。

### 五环腰带

强化皮质工具腰带上固定五枚「行事环」，依次对应 **事、实、法、成、界**。它们既是岱的随身工具收纳系统，也是 odai 最核心的人物识别符号。

正面观看时，五环从画面左至右固定排列为 **事｜实｜法｜成｜界**，也就是从角色自身右侧腰部延伸到左侧腰部。任何视图、Q 版和衍生图都不能调换顺序、增减数量或改成普通链条。

#### 共通结构

- 外径约 48 mm、厚约 11 mm，贴合腰带安装；整体比早期测试稿缩小约 15%。
- 外圈使用有轻微使用痕迹的拉丝旧铜，内圈为精密器械结构，不做珠宝感或大型魔法阵。
- 腰带底座带有机械卡榫与黛青导轨。拇指旋转外环四分之一圈后，圆环可从底座脱离并悬浮在掌前。
- 启动时内圈展开成一道克制的折叠收纳口，对应工具从中解锁；关闭后工具回收，圆环重新吸附到底座。
- 同一时间只允许一枚环完全展开；收纳容量有限，每枚环只能保管职责范围内的工具。
- 能量表现仅使用细窄黛青光线和一枚朱砂状态点，不出现满屏 HUD、粒子风暴或夸张法术光效。
- 「事、实、法、成、界」五个字只在启动时沿内缘短暂显现，常态不直接刻大字；缩小后仍靠不同内部结构区分。

#### 五环设计

| 环 | 内部结构与识别 | 职责 | 主要收纳 |
| --- | --- | --- | --- |
| **事环** | 暖白内芯，顶部有方形起始缺口，像尚未写下第一笔的任务框 | 接住目标，明确要做的事 | 任务册、机械笔 |
| **实环** | 银灰半透明镜片横穿内圈，带一条可滑动的测量线 | 观察、测量、核对事实 | 验证终端、游标卡尺、微型放大镜 |
| **法环** | 黛青双层偏心轨道，可彼此转动并重新对齐 | 选择路线、组合方法、调整做法 | 模块化工具头、制作终端、连接线 |
| **成环** | 最完整的闭合内圈，中央有旧铜锁桥与一枚朱砂确认点 | 验证结果、收束工作、形成可交付成果 | 「验」印、交付匣钥匙、封装扣 |
| **界环** | 深色开口内圈，开口处嵌朱砂止动块，像一道明确的门闩 | 标出权限、风险和必须停下的位置 | 「界」印、安全锁、授权片 |

五环的技术感来自可理解的锁扣、轨道、镜片与折叠结构；玄幻感只来自有限的悬浮和空间收纳。它们不是武器，也不是无限储物法器。

#### 五环状态

| 状态 | 表现 |
| --- | --- |
| **休眠** | 旧铜外圈与深色内芯，无发光，全部贴合腰带 |
| **待命** | 当前环出现一圈极细的黛青引导光 |
| **启动** | 当前环旋转脱离腰带，悬浮并展开内部结构；其他四环保持休眠 |
| **完成** | 成环闭合锁桥，朱砂确认点亮起 |
| **止界** | 界环的朱砂止动块横向锁死，形成明确的门闩视觉 |

五环不能同时完全启动。主立绘中五环全部保持休眠，动作页与细节页才展示启动效果。

## 品牌识别

### odai 五环序列

**事｜实｜法｜成｜界** 的固定五环序列就是岱的图形识别，不再另设一枚独立的环形标志。这样人物本体、Q 版和 README 徽章共享同一个来源明确的视觉系统。

完整人物必须画出腰间五环。只容纳头像的小尺寸场景，可以在头像下方附一排简化五环：保留五枚、固定顺序和各自不同的内芯轮廓，其中成环的朱砂确认点最醒目。

### odai 字标

正式字标固定使用小写 `odai`，不带斜杠。

- 主设人物只在左胸铭牌出现一次字标。
- Q 版可以把字标简化为较大的胸前铭牌；尺寸过小时优先保留五环序列。
- README 徽章必须同时出现 Q 版岱、五环序列和清晰的 `odai` 字标，不能只靠人物让读者猜品牌。

## 标志道具

道具遵循“当前任务只取出当前需要的一件”原则。正式人物图不能把所有装备同时挂在身上；未使用的工具由对应行事环收纳。

### 任务册

黑色窄幅折叠册，旧铜扣合，配一支机械笔。她接手任务时会先拿在手里。

### 验证终端

一台单手可持的耐用小终端，黑色机身，点缀黛青与旧铜。屏幕通常保持简洁，不显示密集数据。

### 验界双面印

一枚掌心大小的旧铜双面印章：一面是朱砂色的“验”，一面是朱砂色的“界”。

- “验”用于结果成立后的确认。
- “界”用于必须停下、交由用户决定的位置。

平时双面印拆分收纳：「验」印由成环保管，「界」印由界环保管；需要成套使用时，两环会把它们组合为同一枚双面印。

### 交付匣

黑色硬质小箱，旧铜锁扣。岱完成工作时会把真正可用的结果放进交付匣，再递给用户。

### 游标卡尺

放在工具袋中的次要道具，代表她习惯先测量，再下结论。

## 标准六态

1. **常态待命**：五环休眠，自然站立，手持合上的任务册，带轻微笑意。
2. **事环接手**：事环待命，展开任务册，明确目标。
3. **实环核查**：实环启动，镜片扫过对象或终端，眉峰略收，视线集中。
4. **法环制作**：法环双轨转动，取出一件模块化工具，挽起袖子并微微前倾。
5. **成环交付**：成环亮起朱砂确认点，盖下“验”印或递出交付匣，露出很轻的满足感。
6. **界环止步**：一只手掌心向前，界环悬浮在掌侧并锁死止动块，坚定但不敌对。

## Q 版

Q 版是岱本人的简化形态，采用约 2.5 头身。它可以可爱，但眉形、眼神与站姿仍保留成年人的沉着感，不能变成银白发幼态 AI 少女。

- 保留墨黑高马尾、右侧银白挑染、黛青发尾、简洁发扣、胸前铭牌、短夹克、暖白短款内层和五环腰带。
- 可以保留一条很窄的露腰轮廓，但不在 Q 版上绘制马甲线细节。
- 简化缝线和工具，但不改变主配色。五环可以比写实比例放大约 20%，并用暖白镜片、银灰镜片、黛青双轨、朱砂确认点和朱砂止动块区分五枚环。
- 固定绘制六态：常态待命、事环接手、实环核查、法环制作、成环交付、界环止步。
- 六态设定页只在常态全身主形象上展示完整腰带，并严格画出事、实、法、成、界五环；其余五个动作裁到腰带上方，只展示当前动作环，避免缩小后出现漏环或重复计数。
- 用于头像、贴纸、表情包和 README 徽章。
